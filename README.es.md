Soy estudiante de **Análisis y Desarrollo de Sistemas en UNINTER**, con graduación prevista para **agosto de 2028**.

Mi principal interés es el **desarrollo backend**, especialmente la creación de aplicaciones, APIs y sistemas que resuelvan problemas reales.

## 🚀 Proyectos Destacados

### 💰 [FluxaMoney](https://github.com/ArthurAlvesVS/controle-financeiro)

Un sistema de gestión financiera personal desarrollado para ayudar a los usuarios a organizar, comprender y mejorar sus finanzas.

El proyecto combina desarrollo backend, persistencia de datos, autenticación, reglas de negocio y visualización de información.

**Principales funcionalidades:**

* Autenticación de usuarios
* Gestión de ingresos y gastos
* Filtros de transacciones
* Dashboard financiero
* Gráficos y visualización de datos
* Diagnóstico financiero
* Metas y proyecciones
* Alertas financieras
* Exportación a CSV y Excel

**Tecnologías:**

`Python` `Flask` `SQLAlchemy` `SQLite` `HTML` `CSS` `JavaScript` `Chart.js`

### 🤖 SmartSupport AI

Una API de análisis de tickets de soporte impulsada por inteligencia artificial, diseñada para ayudar a automatizar la clasificación inicial de solicitudes de clientes.

El proyecto combina desarrollo backend, integración con inteligencia artificial, procesamiento estructurado de datos, persistencia y pruebas automatizadas.

**Principales funcionalidades:**

* Análisis de tickets de soporte
* Categorización automática
* Clasificación de prioridad
* Resumen de solicitudes
* Sugerencias de respuesta generadas por IA
* Respuestas estructuradas mediante API
* Persistencia de datos con SQLite
* Pruebas automatizadas

**Tecnologías:**

`Python` `FastAPI` `Gemini API` `SQLite` `Pytest` `REST API`
